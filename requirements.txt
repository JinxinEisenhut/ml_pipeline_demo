# requirements.txt – Python-Abhängigkeiten mit fixierten Versionen
#
# Warum fixierte Versionen (==) und nicht ">="-Ranges?
#   Reproduzierbarkeit: In 6 Monaten soll derselbe Build dasselbe Ergebnis liefern.
#   sklearn 1.5 könnte andere Defaults haben als sklearn 1.3.
#   pip install scikit-learn ohne Version zieht immer die neueste → nicht reproduzierbar.
#
# Wie erstellt man diese Datei?
#   pip freeze > requirements.txt  (nach manueller Installation)
#   Oder: pip-tools (pip-compile) für saubereres Dependency-Management
#
